# Restaurant Sales Performance Analysis | Excel Dashboard

An interactive **Excel-based data analytics project** designed to analyze restaurant sales, customer behavior, and order performance across multiple cities. The project uses data cleaning, PivotTables, KPI analysis, and interactive dashboard visualizations to transform raw food-delivery data into actionable business insights.

## 📊 Project Highlights
* Analyzed **18,000+ food delivery orders** across **4 cities**.
* Processed and analyzed **17,683 completed orders** with a **98% completion rate**.
* Generated **$2.36M total revenue** from **52K+ quantities sold**.
* Calculated key KPIs including **Revenue, Orders, Quantity Sold, Completion Rate, and Average Customer Rating (4.3)**.
* Analyzed sales performance by **city, restaurant type, customer type, payment method, weather, traffic level, and day of week**.
* Identified key patterns in **customer behavior, order performance, cancellations, and revenue distribution**.
* Built an interactive **Excel Dashboard** using PivotTables, charts, KPI cards, slicers, and visualizations.
